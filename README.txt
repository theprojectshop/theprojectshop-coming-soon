THE PROJECT SHOP — COMING SOON WEBSITE

Upload BOTH index.html and logo.png to the root of your GitHub repository.
Do not upload only the ZIP file.

Then open repository Settings > Pages:
- Build and deployment: Deploy from a branch
- Branch: main
- Folder: /(root)
- Save

After the GitHub Pages site is published, add the custom domain theprojectshop.online under Settings > Pages, then configure Namecheap DNS using the steps in ChatGPT.
